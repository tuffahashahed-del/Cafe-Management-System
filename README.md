# Cafe Management System

A simple cafe management system developed using C#, SQL, and Windows Forms.

## Features
- User sign-in and sign-up
- Manage cafe products and categories
- Manage inventory
- Manage customers
- Simple dashboard interface
- Database integration using SQL

## Technologies
- C#
- SQL
- Windows Forms
- Visual Studio

## Project Type
University project
